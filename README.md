# [Scarl](https://github.com/user/scarl) — Professional Image Reconstruction

**"ITS RAZE SO ITS CRAZE"**

Scarl is a high-performance, AI-powered image upscaling and reconstruction suite. Built with a high-speed Rust core and a sleek C# WPF interface, Scarl delivers professional-grade results using state-of-the-art models like Real-ESRGAN and HAT.

##  Vision
Scarl is committed to being **100% Free and Ad-Free**. No subscriptions, no data harvesting, no hidden costs. All AI inference happens locally on your hardware.

##  Features
- **40K Reconstruction**: Massive resolution support with a dynamic resolution wheel (2K to 40K).
- **Recursive AI Upscaling**: Intelligent multi-pass upscaling for extreme clarity.
- **DirectML GPU Acceleration**: High-speed processing using your Windows GPU.
- **Professional Presets**: Specialized modes for Stickers, GIFs, and Pixel Art.
- **De-Pixelate Engine**: Automated detection and smoothing for low-quality sources.

##  Tech Stack
- **Core**: Rust (using `ort` for ONNX Runtime with DirectML)
- **UI**: C# / .NET 11 (WPF)
- **Mobile**: .NET MAUI (Planned)
- **Installer**: NSIS
